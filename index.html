How this was checked

  • LeetCode company frequency. This is LeetCode Premium's company-tag data, as mirrored in liquidslr/leetcode-company-wise-problems. The mirror was last updated 16 Aug 2026. Its "30 days" list therefore covers 17 Jul – 16 Aug and falls inside your window. Only problems that LeetCode tags as Dynamic Programming are included, and only for companies in or above the ₹50 LPA – ₹1 Cr band. Service companies are excluded.
  • Dated interview write-ups. These come from LeetCode Discuss posts and PracHub, a site of candidate-reported questions that each carry a date. A PracHub problem is linked to the LeetCode problem with the same statement. Where the reported question is a variant, the row says so.
  • Reddit, X and LinkedIn. I searched for each top problem on all three. Search results there aren't filterable by date or question, so nothing came back that I could pin to a specific problem and date. No row relies on those platforms. A problem you also see in recent posts there is extra signal.
  • Frequency is not a guarantee. A company tag means candidates reported the problem in that window. It doesn't mean every interviewer asks it.
  • DP was asked but not named. Zomato SDE-1, Aug 2026: a hard DP problem in round 2 (post). Google L4 India OA, Aug 2026: a hard DP problem (post). Gameberry Labs SDE-1, Jun–Jul 2026: a recursion-to-DP OA problem (post).
